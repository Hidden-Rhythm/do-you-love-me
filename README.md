## 💌 What Is This?

**Do You Love Me?** is a small interactive romantic web experience built with plain **HTML, CSS, and JavaScript**.

It starts with one very important question:

> **Do you love me? 🥺💗**

The visitor can choose **Yes** or **No** — but the No route gets progressively more dramatic. 😭

Eventually, the final **No** button refuses to cooperate and starts moving around the screen.

## 💕 The Yes Path

Choosing **Yes** takes the visitor to `yes.html`.

The response:

> **Hehehehe, I knew it! Love you a lot 😘**

A simple little happy ending. 💗

---

## 🙈 The No Path

The No route contains three progressively more dramatic pages.

### `no1.html`

> **Please think again! 🥺💞**

The visitor gets another chance to choose Yes.

### `no2.html`

> **Ek aur baar soch lo! 😣💗**

Still not giving up.

### `no3.html`

> **Baby Man jao na! Kitna no karogi aap😭**

And then comes the final trick:

**the No button starts moving around the screen when hovered.** 🏃

---

## 🏃 The Moving No Button

The final No button is controlled by `script.js`.

On hover, JavaScript gives the button a random position within the viewport.

So technically...

**No is still an option.**

It's just increasingly difficult to click. 😭

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/Hidden-Rhythm/do-you-love-me.git
cd do-you-love-me
```

Then open `index.html` in your browser.

Or start a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
